# Cykelvejr – overlay-version

Denne version bygger på det oprindelige detaljerede layout, men med:
- samlet topbjælke med titel + dato
- grøn/gul/rød baggrund efter samlet score
- animeret cyklist på hver enkelt tur
- turen har sin egen score 0–100
- turens baggrund bliver grøn/gul/rød efter den individuelle score
- regn/vind/sne-animation kan vises oven på cykelturen
- tryk på cykelturen for at se detaljer
- knap til at gå tilbage til animationen
- påklædningsknappen er altid synlig under turene
- vind vises i m/s

Upload alle filer til et GitHub repository og slå GitHub Pages til.
