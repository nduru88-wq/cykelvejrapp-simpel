# Cykelvejr overlay v2

Ændringer:
- Forsiden viser kun navn/retning, stor cyklist, vejranimation og tur-score.
- Detaljer vises først ved tryk.
- Peter er en voksen brun mand på cykel.
- Charlie er en yngre brun cyklist.
- Cyklisten kører på stedet: hjul, pedal, ben og krop er animeret.
- Hjemturen vender cyklisten den modsatte vej.
- Vejrsymbolet står på stedet og er let animeret.
- Vind vises nu som rene luftstrømme i stedet for emoji.
- Påklædningsknappen er altid synlig.
