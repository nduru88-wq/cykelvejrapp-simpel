# Cykelvejr – enkel version

Denne version er lavet som et alternativ til den mere detaljerede udgave.

Den viser kun:
- samlet cykel-score
- temperatur
- vind i m/s med grøn/gul/rød vurdering
- regn i mm med grøn/gul/rød vurdering
- morgen og hjemtur
- påklædningsknap

## GitHub Pages
Upload alle filer til et nyt repository og slå GitHub Pages til:
Settings → Pages → Deploy from a branch → main → / (root)
